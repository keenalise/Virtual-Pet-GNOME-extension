Project: Interactive Desktop Dog – Native GNOME Shell Extension
Act as a senior Linux desktop developer specializing in GNOME Shell extensions, GJS, JavaScript, GTK, and GNOME Shell internals.
I want you to develop a complete, working, native GNOME Shell extension that displays a cute animated dog on my Ubuntu desktop.
This must be a proper GNOME Shell extension, NOT a standalone application.
1. My system specifications

* Operating System: Ubuntu 24.04.4 LTS
* Desktop Environment: GNOME 46
* Display Server: X11
* Architecture: x86_64
* Window Manager: Mutter
* Extension Manager: Installed
* Programming environment: GJS / JavaScript

Target GNOME Shell version 46. Make sure the implementation uses APIs compatible with GNOME 46.
2. Main concept
Create a cute, small, animated pixel-art dog that lives on my desktop.
The dog should behave like a little virtual companion.
IMPORTANT: I DO NOT WANT a dog that constantly runs, jumps, falls from the top of the screen, climbs windows, or moves around automatically.
The dog must remain stationary unless I interact with it.
3. Required features
A. Dog appearance

* Create an original, adorable pixel-art puppy.
* Use a transparent background.
* The dog should have a cute appearance, expressive eyes, and a friendly personality.
* Use high-quality pixel-art sprites.
* Make the dog relatively small, approximately 100–150 pixels in visual size.
* Include multiple animation states.

B. Idle behaviour
When the user does nothing, the dog should:

* Remain in its current position.
* Occasionally blink.
* Occasionally move its ears or tail.
* Have subtle breathing animations.
* Never automatically walk or jump around the desktop.

C. Interactive behaviour
Implement these interactions:

1. Single click: The dog reacts happily.
2. Double click: The dog performs a playful animation.
3. Click and hold: Allow the user to drag the dog anywhere on the screen.
4. Release after dragging: The dog remains exactly where it was dropped.
5. Right-click: Display a small context menu.

The context menu should include:

* Pet the dog.
* Feed the dog.
* Play animation.
* Sleep / Wake up.
* Toggle sound.
* Reset position.
* Hide / Show dog.

D. Dog animations
Create separate animations for:

* Idle.
* Blinking.
* Happy.
* Tail wagging.
* Sleeping.
* Eating.
* Playing.
* Being petted.

Use sprite sheets or individual transparent PNG/SVG assets.
All animations should be smooth and lightweight.
E. Positioning

* The dog should initially appear in the bottom-right corner.
* It must stay at its current screen position.
* Allow dragging to reposition it.
* Remember its last position when GNOME Shell restarts.
* Add an option to reset its position.
* Make it possible to hide and show the dog.

F. Performance

* Keep CPU and RAM consumption low.
* Avoid unnecessary animation loops.
* Only run animations when necessary.
* Use GNOME Shell's supported animation and actor APIs.
* Clean up timers, signals, actors, and event handlers when the extension is disabled.

4. Technical implementation
Build this as a native GNOME Shell extension using:

* GJS.
* GNOME Shell extension APIs.
* St.Widget / appropriate GNOME Shell actors.
* Clutter animation and event APIs.
* CSS for styling.
* GSettings for persistent settings if appropriate.

Use a transparent overlay actor integrated into the GNOME Shell stage.
The dog should appear above normal desktop windows if possible, without blocking normal mouse interaction except when the pointer is actually over the dog.
Do not use:

* Electron.
* Python desktop overlays.
* Qt.
* Web-based desktop applications.
* External background services.
* Unnecessary third-party dependencies.

Do not disable GNOME Shell security features.
